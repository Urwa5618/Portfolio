# 🌐 Personal Portfolio Website

A modern, responsive **personal portfolio website** built to showcase my skills, experience, certifications, projects, and development journey as a Computer Science student and developer.

The website provides a professional online presence where visitors can learn about my background, explore my work, view my certifications, and get in touch with me.

---

## 📌 About

This portfolio was created to bring my **academic journey, technical skills, development experience, projects, and achievements** together in one professional website.

The main focus of the website is to provide a clean and modern user experience while making important information easy to find.

The portfolio is designed with a **developer-focused dark interface**, responsive layouts, interactive elements, smooth animations, and a simple navigation system.

## ⚡ Interactive Features

JavaScript provides several interactive features throughout the website.

### Mobile Navigation

The hamburger menu opens and closes the navigation menu on smaller screens.

### Theme Toggle

Visitors can switch between dark and light mode.

### Theme Persistence

The selected theme is saved using browser `localStorage`.

### Project Filtering

Projects can be filtered according to their categories.

### Active Navigation

The navigation automatically identifies the current section while scrolling.

### Scroll Animations

The website uses the **Intersection Observer API** to reveal selected elements as they enter the viewport.

### Contact Form

The contact form submits messages through Web3Forms without requiring a custom backend.
